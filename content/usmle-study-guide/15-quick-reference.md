# Chapter 15 — Quick Reference

> **Sprint sheet.** Confirm numbers against current guidelines before any clinical use.

## Unstable first

| Presentation | First move |
| --- | --- |
| STEMI | Aspirin + P2Y12 + cath activation |
| Anaphylaxis | IM epinephrine |
| Status epilepticus | IV lorazepam (or IM midazolam) |
| Tension pneumothorax | Needle / finger decompression, then chest tube |
| Tamponade | Echo → pericardiocentesis |
| Hyperkalemia + ECG changes | IV calcium |
| Neutropenic fever | Cultures → anti-pseudomonal beta-lactam |
| Thunderclap, CT− | LP |

## Stroke clock

- CT first to exclude blood.
- Lytic window if eligible; BP <185/110 before lytics.
- Permissive BP if not lysing.
- SAH: CT → LP → nimodipine.

## Electrolytes

- Hyper-K ladder: stabilize → shift → remove.
- Chronic hypo-Na: ≤8 mEq/L/day.
- Symptomatic hypo-Na: small 3% aliquots.
- Replete Mg with refractory hypo-K.

## ID empiric starts (themes)

- Inpatient CAP: beta-lactam + atypical.
- Meningitis: CTX + vanco ± amp; steroids with first dose when pneumococcus likely.
- MRSA pneumonia: vanco or linezolid — not daptomycin.
- C. diff: oral vanco or fidaxomicin.

## HFrEF pillars

ARNI/ACEi/ARB + evidence-based BB + MRA + SGLT2i.

## CCS reminder

Stabilize → diagnose → treat → **advance the clock and follow the vital**.
