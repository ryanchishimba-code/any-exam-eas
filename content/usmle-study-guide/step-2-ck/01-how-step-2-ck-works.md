# How Step 2 CK works

## The outline

Step 2 CK is a one-day clinical-knowledge exam. The score is reported as a number. This book does not state a passing score, a mean, or an item count. The bulletin is the source of truth for the day.

Recorded task ranges (2026-09-06; the live page wins if it has changed):

| Task | Recorded range |
| --- | --- |
| Diagnosis | 35–45% |
| Foundational science | 10–20% |
| Pharmacotherapy | 10–20% |
| Clinical interventions | 10–20% |
| Health maintenance | 8–15% |
| Communication and systems | 8–15% |
| Practice-based learning | 3–8% |

Clinical fields overlap and do not sum to 100%. Recorded shares: medicine about 55–65%, pediatrics about 17–27%, obstetrics and gynecology about 10–20%, psychiatry about 10–15%, surgery about 5–15%.

System ranges worth planning around: cardiovascular about 6–12%, respiratory about 5–10% inside a wider respiratory-renal band, gastrointestinal about 5–10%, and the social-science band about 10–15%. Use the outline page, not a forum pie chart.

**What "next step" means**

- Unstable: the stabilizing act, even if a diagnosis is unfinished.
- Stable, diagnosis unclear: the test that would change management.
- Diagnosis known: the first treatment the guideline names for that situation, not the third-line drug.

## Common traps

- Answering with the definitive test when the stem asked for the next test.
- Skipping health maintenance because it feels like clinic. It is a large task range.
- Importing a Step 1 mechanism as the final answer when the stem asked what you do.
